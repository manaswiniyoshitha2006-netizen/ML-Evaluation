# Machine Learning Capstone Project

## Project Overview

This project develops an end-to-end Machine Learning pipeline for
telecommunications customer intelligence using the Telco Customer
Churn dataset.

The project covers three Machine Learning tracks:

- Regression
- Classification
- Clustering

The Regression track focuses on predicting Customer Lifetime Value
(CLTV) as a continuous target. The Classification track focuses on
predicting customer churn, while the Clustering track aims to identify
meaningful customer segments based on customer characteristics,
services, billing, and behavioural information.

The complete workflow includes data loading, exploratory data analysis,
data cleaning, feature engineering, preprocessing, model training,
model comparison, hyperparameter tuning, cross-validation, and result
visualisation.

## Problem Statement

Telecommunications companies need to understand customer behaviour
and customer value to support effective customer management, retention,
and business decision-making.

This project uses demographic, tenure, service, billing, satisfaction,
and behavioural information from telecommunications customers to build
Machine Learning models for three tasks:

1. Regression — estimate Customer Lifetime Value (CLTV).
2. Classification — predict whether a customer is likely to churn.
3. Clustering — identify groups of customers with similar characteristics.

Each track follows a consistent Machine Learning workflow with
appropriate preprocessing, model evaluation, comparison, and
visualisation.
